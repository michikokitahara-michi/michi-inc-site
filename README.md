# MICHI inc. サイトの元データ（source ブランチ）

公開中のサイト（main ブランチ / https://michi-inc.net/）を生成した元データです。

- `design/` … 各ページのデザインデータ（.dc.html）
- `export-tool/export.py` … デザインデータから公開用HTMLを書き出すスクリプト
- `export-tool/hero2.py` … トップの点と線のアニメーション生成
- `visuals/` … 追加した写真・アイコン・シェア画像

小さな修正は main ブランチのHTMLを直接編集しても構いません。
